# 产品决策与施工口径（2026-11-23）

D1、D7 的请示路线来自用户已明确的 COORD-05 裁决。其余标为本轮施工选择，供 coder 直接实施与验证；涉及设备安装、签名凭据或实际外发时，仍按具体操作取得授权。各卡原有验收状态继续以实测证据为准。

| 编号与任务 | 当前决定 | 验收及尚缺证据 |
|---|---|---|
| D1　COORD-05、CLIENT-01 | 由认证宿主提供秘书是否激活及实际呈交端口，缺省关闭。运行中每项待决只选一个通道，重试沿用同一待决 ID。已知未激活时直接呈交用户；已激活但投递失败或权威状态读取失败时保留待呈交并重试，避免双发。 | 门面到用户答复、恢复 ready set 已有组合证据。仍须验证实际宿主启停、投递失败恢复、真实反馈发起及中间层自行结案。秘书回执不能恢复任务。 |
| D2　AUDIT-REPAIR-01 | 首版采用个体序列节点取消。对派发前已取消的节点，由派发层阻止启动；不因此扩展 mission 状态枚举。在途执行沿用现有取消契约。 | 经真实派发入口取消节点，断言 worker 启动次数及新增目标提案文件均为零，并保留可派发对照。proposeGoal 的工具子集约束已于原卡收口。 |
| D3　AUDIT-REPAIR-01 | DiskCache 保留为已验证的候选组件，本批不接入生产。出现可重复的确定性读热点后再选接入点。 | 重开须有重复读成本、失效键、权限隔离和净节省对照；当前不计入生产收益。 |
| D4　WIRING-04-01 | 任务定义版本和执行尝试分别记录。由权威派发器在任务链对应节点持久化单调 attempt；任务内容修订独立推进 taskRevision。同一逻辑派发重投复用 attempt，真正重新执行才递增。生产者从派发记录盖章，消费者与当前节点比较。 | 覆盖旧尝试迟到、同次重投、仅修改兄弟节点、重启恢复及旧信封缺字段。缺章标为不可验证；涉及推进状态时转入对账，不能猜测当前值。沿用 §28 已裁决的意图台账加权威证据对账。 |
| D5　EXEC-01、SEC-02 通道 6 | 模型可见执行输出采用 block，完整扫描得到 clean 后方可交出；非 clean、扫描异常和未判定的跨块尾部不释放正文。保持预算、游标与脱敏诊断。B1 先验证 Windows 已有隔离后端，全套文件、网络、资源隔离通过前标为未验证。Linux/macOS 按独立平台证据启用，首版不依赖已弃用的 macOS 后端。 | B2 复用已具备的构建环境，新工具链、提权安装、签名或公证单独申请；B3 首版按平台与架构使用独立版本化安装包，仅发布通过验收的组合；B4 是干净设备外部验收，记录实际可用设备与结果。缺后端时拒绝执行。测试扫描跨块、异常、截断及正常输出。 |
| D6　SEC-02 通道 15、REMOTE-01 | 保留远程能力设计，首版延后真实远端投递。现有已装配且会把材料送出授权边界的出口须逐一列账，在首次实际发送前校验目的端、资源范围、内容判定与授权 revision。尚无消费者的路径报告不可用。 | 有出口则用受控接收端验证过期、撤销或越界时零发送。新增远程通道须先有认证目标、平台投递能力与回执再进入发布验收。 |
| D7　COORD-02、COORD-04、COORD-05 | 本轮不注册 sendCollaborationRequest 为模型写工具。Worker 通过反馈信箱逐级请示，本级有权且能决定就结案；到主层仍未决只呈交用户或已激活秘书。原有宿主定向通信继续使用。 | 本级结案后上层零消息；主层未决时同级零收件、用户仅一项待决。保留宿主定向消息回归。此项关闭产品选型问题，生产装配另验。 |
| D8　SEC-02、B6R-11 | 维持全局分支 85%、指定四模块各 95%。按风险先补敏感内容判定、入口、策略包装与信箱日志的真实分支。 | 重新生成覆盖率，逐模块列出分母及未覆盖分支；包级门禁单列执行。上一轮 80.78% 属于历史基线。 |

相关状态纠偏：ALIGN 交接中的 GOAL_MODE_DEFAULT_ENABLED 二选一已由源码落实为移除死常量，认证用户运行时配置决定激活。ALIGN-03 §末尾已有 01/04 施工裁决；历史问题无须重复请示。
