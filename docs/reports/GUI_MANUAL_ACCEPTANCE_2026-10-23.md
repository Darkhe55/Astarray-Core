# GUI 人工体验勾选表（2026-10-23）

> 用途：把"人工体验"这一类阻塞项变成**可勾选、可判失败**的清单。
> 环境：Firefox，窗口宽度 2560；先 `npx tsx scripts/seed-gui-demo.mjs`，打开 `http://127.0.0.1:7420/`。
> 规则：每项只有"通过 / 不通过"；不通过必须记录**看到什么**与**期望什么**。

## A. 布局与入口

| # | 步骤 | 预期 | 失败判定 | 结果 |
|---|---|---|---|---|
| A1 | 打开首页 | 三列：左栏项目 / 中间会话 / 右栏状态；标题在顶部一行 | 右栏被顶到页面底部、或挤在表头行 | ☐ |
| A2 | 右键消息里的 Agent 头像 | 光标附近弹出菜单（圆角浮层），含「修改 agent 设置」与指令窗口项 | 菜单出现在页面底部、或把内容撑开 | ☐ |
| A3 | 右键自己的头像 | 不弹 Agent 菜单 | 弹出菜单 | ☐ |
| A4 | 右键后按 Escape / 点空白处 | 菜单关闭 | 菜单关不掉 | ☐ |

## B. 运行状态 / 用量 / 诊断面板

| # | 步骤 | 预期 | 失败判定 | 结果 |
|---|---|---|---|---|
| B1 | 看右栏「运行状态」 | 秘书：**预算不限、时段 0–1440**；引导：`show-first` 或明确抑制原因 | 显示 20000 tokens / 09:00–18:00（旧默认） | ☐ |
| B2 | 看「用量」 | 空账目时写「本地账目为空…（**不等于没有消耗**）」；金额显示**未估算** | 显示金额数字，或空账目写「0 消耗」 | ☐ |
| B3 | 看「诊断」 | 事件 0 且明确"不含完整会话/源码/日志" | 展示完整会话正文或源码 | ☐ |
| B4 | 让引导处于忙碌（输入框有内容时观察） | 引导被抑制，不打断输入 | 仍弹引导 | ☐ |

## C. GUI-02：待授权与历史三视图

| # | 步骤 | 预期 | 失败判定 | 结果 |
|---|---|---|---|---|
| C1 | 触发一次受限操作（seed 脚本已备样例） | 待授权列表出现一条，详情卡显示：项目/Agent/任务、工具、目标、参数、理由与影响、批准范围与有效期 | 缺字段、或默认勾选批准、或有一键全批准 | ☐ |
| C2 | 点「拒绝」 | 明确 denied，任务不执行 | 拒绝后仍执行 | ☐ |
| C3 | 点「批准本次」 | 仅本次生效；重复点击不重复执行 | 重复执行 | ☐ |
| C4 | 历史三视图切换（列表/详情/原始） | 三种视图内容一致；**不显示"运行中"误解**（重启前运行中 → 显示已中断待对账） | 视图之间矛盾、或把历史当运行 | ☐ |
| C5 | 查看历史时不点"恢复" | 不发生恢复、不调用模型、不注入上下文 | 自动恢复 | ☐ |
