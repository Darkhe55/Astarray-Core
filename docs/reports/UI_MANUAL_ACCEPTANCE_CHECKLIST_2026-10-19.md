# UI 人工体验清单（2026-10-19）

> **这是"人工证据"模板，不是自动化测试结果。**
> 未填写的项一律视为**未验证**——不得因为清单存在就宣称"人工体验已通过"。

## 前置（约 2 分钟）

私有 UI 仓库：`../astarray-ui`（与公开库同级）。

```powershell
cd ../astarray-ui
pwsh -File ./setup-links.ps1   # 建立 packages/core 与 node_modules 的 junction
npm run build                  # 产出 dist/cli.js
node dist/cli.js gui serve --port 0 --no-open
```

启动后终端会打印本机地址（`http://127.0.0.1:<port>`）。**只监听 loopback**。

体验过程中如需命令行辅助，可在公开库执行：

```powershell
node dist/cli.js project status --project <id> --root <path> --json
node dist/cli.js obs diag --json
node dist/cli.js obs diag export --output .\evidence.json --since <iso> --until <iso> --platform <name> --redaction "已脱敏"
```

## 五个必测流程

对每一项，只记录三件事：**能否看懂** / **能否完成** / **哪里别扭**。

| # | 流程 | 操作 | 预期现象 | 结论（通过/不通过/备注） |
|---|---|---|---|---|
| 1 | **冷启动项目状态** | 打开首页，选择/查看当前项目 | 页面明确显示"能否加载历史 / 能否执行任务 / 需要你做什么"；**身份不一致时不会直接允许执行** | |
| 2 | **待授权卡批准 / 否决** | 提交一个会写文件的任务，等"待授权"出现 | 待授权区**有内容**（不是空白）；卡片显示工具名与操作、**不含原始参数**；批准后任务继续、产物落盘；否决后任务停下且**不写盘** | |
| 3 | **历史与过程说明** | 打开任务历史，切换显示开关 | 关掉"过程说明/工具调用"后**只隐藏不删除**；重新打开能看到；控制序列不显示为乱码（脱敏生效） | |
| 4 | **设置修改** | 改一个低风险设置（如模式） | 显示"旧值 → 新值"与影响；保存后状态明确（已保存/已生效）；**含糊范围会先询问**而不是直接改 | |
| 5 | **证据包导出** | `obs diag export` 导出到本地文件 | 生成 JSON 文件；文件里**没有**原始错误文本/命令参数/凭据；输出明确"未联网上传" | |
