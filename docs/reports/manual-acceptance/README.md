# 人工判定清单（单文件网页）

本目录把 [`docs/reports/GUI_MANUAL_ACCEPTANCE_2026-10-23.md`](../GUI_MANUAL_ACCEPTANCE_2026-10-23.md) 里的
A–J 人工判定清单，做成了一个可离线打开的单文件网页，方便逐项打勾、填备注、导出结果。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部内容（HTML + 内嵌 CSS + 内嵌 JS + 内嵌 JSON 数据）。无外部依赖、无 CDN、无网络请求。 |

## 怎么打开

任选一种：

1. **双击打开**：在文件管理器里直接双击 `index.html`，用默认浏览器打开即可（`file://` 协议可用）。
2. **命令行打开**（Windows PowerShell）：
   ```powershell
   start .\docs\reports\manual-acceptance\index.html
   ```
3. **本地静态服务**（可选，非必需）：
   ```powershell
   cd astarray
   npx serve docs/reports/manual-acceptance
   # 然后访问 http://127.0.0.1:3000/
   ```

> 注意：被测的 GUI 页面本身需要先启动服务：
> `cd astarray-ui && npx tsx scripts/seed-gui-demo.mjs --port 7420`，然后打开 `http://127.0.0.1:7420/`。
> **GUI 页面在服务启动时生成，改完必须重启服务再看。**

## 功能

- **分组卡片**：A–J 共 10 组、49 项，每组一张卡片。每项显示 `# 编号`、要判什么（步骤）、通过标准（预期）、失败判定。
- **结果选择**：每项三个单选按钮 —— `通过` / `不通过` / `未测`。
- **不通过备注**：选「不通过」时自动出现文本框，要求分三行写「看到什么 / 期望什么 / 复现步骤」；未填写该项标为 **不完整**。
- **进度条**：顶部显示「已通过 N / 49」，并分别统计 `通过 / 不通过 / 未测 / 不完整` 数量；每组卡片标题右侧也有分组小计。
- **自动保存**：状态与备注自动写入 localStorage，键名 `manual-acceptance-2026-10-24`，刷新不丢。
- **清空全部**：需二次确认（两次 `confirm`）。另有「仅重置结果（保留备注）」。
- **导出 Markdown**：生成与原文档同结构的表格（含每项结果与备注列），下载为 `manual-acceptance-result.md`。
- **键盘可用**：所有单选项可用 Tab 聚焦、方向键切换；焦点轮廓可见（3px 描边）。

## 手动验收步骤（针对这个页面本身）

1. 打开 `index.html`，应看到 10 张分组卡片、49 个条目，顶部进度条显示「已通过 0 / 49」。
2. 在任一项选「不通过」→ 备注框出现 → 不填内容时该项徽标应变为「不完整」，「不完整」计数 +1。
3. 填写备注后徽标变为「不通过」，「不通过」计数 +1。
4. 刷新页面（F5）→ 刚才的选择和备注应仍在。
5. 点「导出 Markdown」→ 应下载 `manual-acceptance-result.md`，内容结构与原文档一致（各组一个表格，列为 `# | 步骤 | 预期 | 失败判定 | 结果 | 备注`）。
6. 点「清空全部」→ 两次确认后全部回到「未测」，备注清空。
7. 用键盘 Tab 走一遍，焦点轮廓应始终可见。

## 注意事项

- 状态保存在**当前浏览器**的 localStorage 里，换浏览器/无痕窗口不共享；清浏览器数据会丢失。重要结果请用「导出 Markdown」落盘。
- 导出的 Markdown 中，「不通过但备注缺失」的项会被标记为 `☒ 不通过（**不完整**：备注未填写）`，以便在结果文档里仍然可见。
