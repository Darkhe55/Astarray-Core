## 4. GUI-03-02：作用域配置基础（F04/F06/F10）

- 统一解析应用默认 → 项目覆盖 → 会话覆盖，显示原始值、继承来源、配置版本、生效版本。该继承用于可配置字段；权限还须经过不可配置不变量和上级授权边界求交，不是下级覆盖上级安全限制。
- 编辑请求包含明确 scope、projectIdentifier、sessionIdentifier（按范围适用）与 expectedRevision。后端从会话主体确定权限，不接受前端伪造主体；跨项目写入拒绝。
- 为已有设置增加可选作用域字段，兼容旧配置，不生成第二套权限策略。采用现有原子保存/备份机制；过期 revision 返回冲突，保留用户草稿。
- F04：项目权限页支持当前已设计的三态和权限组，恢复继承；放宽权限走现有显式确认流程。主 Agent 工具限制及跨项目只读不变。
- F06/F10：默认全局上下文预算仍为 4096 token；复用核心合法值规则，降低到当前用量以下时按既有节点暂存规则生效，不截断原文或引入有损压缩。

## 5. GUI-03-03：会话与授权控制（F07/F08/F09/F12）

- F07：提供队列/引导/智能，智能容量默认 3；保存后下一条指令采用新策略。降低容量不丢弃已接收指令，不把早停视为完成释放容量，复用已有指令窗口控制器。
- F08：模型候选来自当前允许列表；切换作用于明确会话/目标 Agent，不改其他 Agent。进行中的调用保持旧模型，新模型在安全点用于后续调用；显示待生效/已生效/失败。缺凭据、能力不匹配或违反用途白名单拒绝；不得静默禁用最后可用沟通模型。
- F09：临时权限只影响会话内有资格的下级 Agent；显示范围、期限、撤销，关闭会话即失效。导出的是脱敏配置模板，不含有效授权票据，导入不能自动获得权限。单次批准与会话预设必须分开。
- F12：复用 `updateParameterAuthorizationSettings` 与现有规则存储。GUI 增加总开关、单工具统一授权和参数细分列表；工具/参数由服务端目录生成。放宽先展示差异，经认证用户明确确认后执行。不得直接信任浏览器提交的 `isConfirmedByAuthenticatedUser: true` 或工具形状列表，服务端绑定主体、配置版本和待确认变更。
- 所有写入复用 Host/Origin、CSRF、身份、归属、revision、幂等检查；不得用前端 disabled 代替服务端检查。

## 6. GUI-03-04：通知、实验与工作时段（F01/F02/F05）

- F01：提供完成、失败、待决策三类应用内通知开关；默认均开。系统通知默认关，仅用户启用后走桌面系统许可；无桌面能力时只提供应用内通知。关闭通知不隐藏待处理中心、不自动批准、不改变安全暂停。
- F02：实验目录只展示已有已实现且有运行时消费者的实验；默认全部关，持久化启停。尚未实现的未来实验保留不可用说明并列为范围外，不在本卡发明实现。禁用仅阻止新启动，进行中操作在安全点结束/暂停；破坏性历史整理仍保留既有独立授权。
- F05：支持时区、每周周期和一次性时间段、工作/休息两种表达；复用 WorkWindow 组件。休息窗口优先禁止分派新任务；进行中操作在安全点暂停，工作时段恢复时重新检查授权和任务状态，防止重复执行。不能强杀正在写盘的工具，也不能只保存时间不接门禁。

## 7. GUI-03-05：工具生命周期（F03）

- 接现有工具包注册、版本控制和取消/回退服务；统一项目/用户范围、版本、权限差异和生效状态。项目工具默认留在本项目，推广到通用工具走独立确认。
- 安装前先询问是否已有本地资源；安装、升级、权限扩大分别显示目标与影响，不能一键批准所有动作。按现有权限模式及项目边界执行，不新增自动放行规则。

- 本卡实施过程中不实际联网安装任何工具；交付生产操作代码，不执行安装演示。不创建通用任意命令 HTTP 入口。
