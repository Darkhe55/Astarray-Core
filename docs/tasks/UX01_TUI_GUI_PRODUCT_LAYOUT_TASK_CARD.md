## 1. 目标、范围与执行位置

这不是换皮或把所有按钮堆进“高级设置”，而是按用户工作流程重建信息层级。保留已有核心能力、权限规则、任务与历史数据，不借 UI 整理删除功能、绕过授权或改变 Agent 职责。

- 实现权威仓库：同级 `astarray-ui`，TUI 位于 `packages/tui/src/ui/`，GUI 位于 `packages/gui/src/`，Electron 壳位于 `desktop/electron/`。
- 核心公共服务在 `astarray`。先核对双库当前依赖与发布方式；不得编辑核心库内未跟踪 UI 副本代替修改权威仓库，不执行可能删除联接目标的初始化脚本。
- CLI 保持脚本友好：现有命令、退出码、结构化输出和非交互流程不因 TUI 改版改变。TUI 不等于把 CLI 帮助打印为满屏菜单。
- 复用 GUI-01/02、HISTORY、SMART、PROJECT、RELOCATE、OBS、模型设置、权限控制面与工具库。建立能力映射后增量修改，不重写第二套调度、权限或状态存储。
- 本卡不开发全部未来功能、不安装远端服务、不启用实验功能、不购买签名证书。缺失能力另列依赖，不能以假按钮、模拟成功或静态示例宣称完成。
- 开始、阻塞、完成时必须更新本卡与相关状态索引；这属于本卡明确授权范围，无需另问。并行冲突时新建独立进度记录，不覆盖并行文本。文档修改不等于编码完成；本轮编码收口后不自动归档为“已验收”。

## 3. 两端共用的信息架构

界面层级最多三级：一级工作区 → 二级任务/设置类别 → 三级具体详情。搜索结果可直达三级，并显示当前位置和返回入口；不得弹窗套弹窗或用一个无限长“更多”面板容纳所有功能。

| 用户目的 | 主入口 | 详情 / 高级入口 |
|---|---|---|
| 交代工作、补充指导 | 会话 | 指令队列、智能窗口、投递对象、模式 |
| 查看执行与处理阻塞 | 任务 | 子任务依赖、负责 Agent、工具步骤、结果、暂停/取消 |
| 审批与验收 | 待处理 | 授权、安装资源确认、澄清、验收、恢复裁决，分类型 |
| 使用成果 | 文件与产物 | 预览、差异、来源、下载/打开，已有编辑能力才提供编辑 |
| 找回以前工作 | 历史 | 搜索、过程说明、工具调用、失败与恢复记录 |
| 管理自动化能力 | 工作流与工具 | 项目工具、个人工具、版本、权限、启停、适用范围 |
| 管理项目与协作 | 项目设置 | 文件夹、Agent、允许模型、跨项目只读协作、工作时段 |
| 管理软件 | 应用设置 | 模型账户、外观、通知、数据备份、实验功能、语言 |
| 查询成本与问题 | 用量与运行帮助 | 请求/token/费用（未知不报零）、错误说明、脱敏支持包 |

应用设置、项目设置、会话设置、Agent 设置必须显示作用范围和继承来源。临时权限显式标记会话有效，跨项目授权不因切换页面扩大。未实现项目覆盖时只显示继承值并解释，不编造“已覆盖”。

## 4. TUI：键盘优先的单主区工作台

### 4.1 默认布局

```text
项目 / 会话     模型 · 模式       运行中 2 · 待处理 1
─────────────────────────────────────────────────
会话主区：用户指令、简短反馈、可折叠工具步骤和结果
长输出默认收起；可展开 / 搜索 / 复制；新输出不抢滚动
─────────────────────────────────────────────────
> 输入指令……             [智能 2/3] [默认：主 Agent]
─────────────────────────────────────────────────
当前状态 · / 命令 · ? 帮助 · 本页快捷键
```

默认只显示状态栏、会话、输入区与一行帮助，不常驻 DAG、Agent 树、文件树和诊断。任务/文件/历史等通过命令面板切换主区；终端宽度达到 120 列时允许用户打开一个 40 列详情侧栏，低于 120 列详情切换为全宽主区，Esc 返回原视图。选择与展开状态按会话保存，不能污染任务状态。

### 4.2 交互约定

- `/` 在输入开头打开可搜索命令面板：项目、会话、任务、待处理、文件、历史、模型、模式、工作流、设置、帮助。命令项显示简短用途与快捷键；路径和正文中间的 `/` 不触发。
- Tab/Shift+Tab 只遍历可见交互区；Esc 关闭当前临时层并返回原焦点，保留草稿。输入区方向键优先编辑，命令面板打开时才用于选项。
- 默认 Enter 发送；`/compose` 进入多行编辑页，Enter 换行、Tab 切到“发送”按钮并 Enter 提交，Esc 返回且保留草稿，不依赖 Shift+Enter。粘贴多行作为单份草稿，不自动提交；输入适配层支持的组合输入状态期间禁止提交，不自行拦截中文字符。
- Ctrl+C 在草稿非空时清空草稿并保留一份可恢复草稿；草稿为空且有前台任务时打开停止确认，其他情况仅提示 `/quit`。`/quit` 打开“保留后台任务并退出 / 停止当前会话任务并退出 / 返回”选择；后端不支持的动作禁用说明，默认选“返回”。不得一次按键误杀全部 Agent。终端原生复制键不重绑定；键位配置置于 TUI 设置中。
- 工具步骤按执行轮次聚合，默认显示工具名称、作用和结果；参数/差异按需展开。开发者可查看技术详情，但非默认输出整份 JSON、内部 nonce、调试堆栈。
- `/tasks` 默认列表，依赖图为可选视图；`/agents` 显示角色、名称、任务、状态，精确身份在详情中可复制。不用长 UUID 占满主区。
- 待授权用独立决策面板，逐项显示目标、影响、关键参数与期限；支持稍后处理，不在等待时锁住会话。安装先询问已有资源，再进入单次批准，不合并成“全部同意”。
- 智能/队列/引导是输入策略，与思索/协同/放权权限模式分开显示；窗口数可调，完成信号不足不得虚假前移。
- 非 TTY 立即给出准确提示和退出码，禁止输出 ANSI 控制串或自动切成另一执行方式。CLI JSON 管道行为维持不变。

### 4.3 尺寸与可访问性

按 80×24、120×30、160×48 编写自适应布局；小于 80×24 隐藏非必要状态与侧栏，保留输入、主区和尺寸提示。复用现有终端显示宽度工具处理中文、emoji、长路径；状态同时提供文字。提供无色/减少动画选项，长输出使用有界渲染。仅在用户位于底部时自动滚动。本卡不要求执行尺寸测试。

## 5. GUI：以项目、对话和成果为中心

### 5.1 主界面布局

```text
应用导航栏             项目 / 会话标题        待处理 · 搜索
┌────────────────┬──────────────────────────────────┐
│ 新建项目       │ 会话与成果主区                    │
│ 项目列表       │ 默认无常驻监控面板                │
│  └ 会话列表    │                                  │
│                │ [按需打开：成果预览 / 任务详情]   │
│ 工作流与工具   ├──────────────────────────────────┤
│ 历史           │ 附件 · 输入框 · 发送              │
│ 设置 / 帮助    │ 输入策略 · 模式（可展开）          │
└────────────────┴──────────────────────────────────┘
```

左侧导航固定 256 CSS px，可收起为 56 px 图标栏；中心占剩余空间。右侧详情默认关闭，仅用户打开任务/产物时出现，默认 360 px、可拖动范围 320–420 px，一次一个。视口小于 1100 px 时详情改为抽屉，小于 900 px 时导航也改为抽屉，顶栏保留打开按钮；两个抽屉不同时打开。不把运行状态、用量、Agent 列表常驻挤占聊天。

### 5.2 多级页面

1. **开始页**：新建项目、打开已有项目、最近项目；一句“从你的工作习惯或要完成的事情开始”。首次选择模型与文件夹提供向导，可跳过浏览；离线状态明确，不伪称模型已连接。
2. **项目工作区**：会话为默认标签；同级提供任务、成果、历史。项目名称旁菜单包含文件夹管理、协作、项目设置与归档。文件夹操作显示影响范围，不能把移除关联等同删除磁盘文件。
3. **会话**：输入框固定在主区底部；发送后立即显示用户消息和真实状态“发送中/已接收/失败可重试”。离线保存与已派发分开，不把 outbox 记录显示为 Agent 已执行。失败时保留草稿、明确重试是否会重复提交。
4. **任务中心**：默认易懂列表，按进行中/待处理/已完成筛选；依赖图是可选标签。详情展示目标、进度、产物、负责对象、阻塞原因；支持合法的暂停/恢复/取消，不用“标记 done”替代验收。
5. **待处理中心**：全局计数、按项目筛选；单条详情展示“需要你决定什么、影响什么、确认后发生什么”。授权、安装、验收、澄清、恢复分别呈现。用户暂不回应不阻断无关项目。
6. **成果与文件**：成果卡优先于裸目录树，提供预览/差异/打开/下载/来源。文本、代码、图片等已有能力按类型适配；未支持的格式如实提供下载，不搭建新的全能编辑器。
7. **历史**：按项目/会话检索；默认消息与关键步骤，按需显示工具调用和过程说明。默认不出现“原始 JSON”标签；查看不续跑、不调用模型、不改变磁盘记录。隐藏不等于删除。
8. **Agent 管理**：项目设置内维护角色/任务/模型与协作关系。头像菜单只放“查看任务、查看状态、设置”等高频动作；所有功能另有普通按钮，不能右键独占。身份、消息来源和授权边界不被昵称遮蔽。
9. **工作流与工具**：项目/个人范围分组，详情包含用途、适用条件、版本、所需权限与最近结果。启用、升级、停用遵循已有授权；缺少能力显示说明及请求入口，不伪装可用。
10. **设置**：左侧分类导航 + 右侧表单，分为常规/外观、模型与账户、权限模式、任务与工作时段、上下文与历史、工具与工作流、数据与备份、实验功能、帮助与关于。搜索可直达设置项并显示作用范围，不要求用户理解内部模块名。

### 5.3 视觉与行为规范

- 使用统一设计 token：间距 4/8/12/16/24 px，控件圆角 8 px、面板 12 px、边框 1 px；主色 #2563EB、危险色 #DC2626，浅色背景 #F8FAFC/正文 #0F172A，深色背景 #0F172A/正文 #E2E8F0。默认跟随系统，允许切换明暗。复用现有图标与系统字体，不安装组件库。不用全屏仪表盘或装饰动画。
- 普通正文 15 px、辅助说明 13 px、页面标题 20 px；表单有永久标签，图标有可访问名称，鼠标目标至少 32×32 px、触控入口至少 44×44 px。
- 长表单使用页面，单个决策用对话框，短详情用抽屉；同一时刻一个模态层。Esc 关闭未提交层；请求提交中不关闭，显示“正在提交”，响应后恢复关闭。焦点限制在模态层内，关闭后回到触发控件。
- 使用可换行、min-width:0 与单栏断点兼容小视口和页面缩放；代码/表格仅局部滚动。本卡不要求运行分辨率或缩放测试。移动端完整交付仍属未来计划，不因响应式布局宣称支持手机办公。
- 页面保存提示区分“已保存配置”“等待安全点生效”“已生效”“应用失败”。切模型不得悄悄丢掉会话或绕过防断连确认。

## 6. 从普通界面移除什么，保留什么

| 内容 | 处理 |
|---|---|
| mock/seed/fixture、测试事件注入、验收脚本按钮、制造失败 | 从发布 UI 与普通菜单移除；仅专用开发启动入口可用，不混入生产路由 |
| raw JSON、schema/revision/IPC、内部组件“已装配”、堆栈、调试 ID | 从普通页面移除；必要脱敏详情只进入支持包。已有开发诊断入口保留在开发启动路径，不新增普通 UI 的开发模式开关 |
| “按 Agent 隔离”“未注入端口”“DTO”等内部说明 | 改为动作与影响说明，如“暂无记录”“此功能尚不可用”；具体原因留在技术详情，不隐藏错误 |
| 运行进度、暂停/取消、调用步骤、来源、错误码 | 保留用户可用的呈现；简短原因与建议默认显示，技术细节按需展开 |
| 用量、费用、故障诊断、恢复与备份 | 属用户功能，不删除；转到适当二/三级页面，未知不显示零 |
| 权限细分、模型配置、上下文预算、实验开关 | 属高级产品设置，不是开发调试；可搜索、可展开、说明清楚，不砍功能 |

开发诊断不是另一个宽权限模式。不得新增用户可绕过安全策略的开关。开发专用入口使用显式开发启动配置，发布包默认不包含测试注入路由/样例数据；隐藏按钮不等于关闭后端能力。面向用户的支持包需预览范围、脱敏、确认导出，不自动上传。

## 7. 功能完整性与数据安全

UX-01-01 必须交付“能力 → TUI 入口 → GUI 入口 → 公共 API → 权限 → 实现状态”的逐项矩阵，覆盖第 3 节和已有任务卡。状态使用已接线/受限/未实现/未来，不把静态查阅写成“已验证可用”。未实现项按第 0 节展示不可用状态，不新增后端任务作为本卡阻塞前驱。

必须覆盖权限模式（三态、工具及参数细分、会话临时提升/导出）、模型账户及用途预设、指令策略与队列、Agent 管理、文件夹/跨项目授权、工作时段、上下文预算/节点回访、恢复、历史、备份、工具包、实验功能。已有功能不能因“简单”变成不可发现的隐藏开关。

权限仍由公共控制面执行，GUI/TUI 只呈现结果；主 Agent 和下级权限、跨项目只读等既有边界不变。设置采用 revision 与有效主体，前端 disabled 不是权限校验。密钥不回显、不进入日志/历史/导出。

所有界面重组均不删除会话、产物或备份；覆盖/迁移前先备份。改导航 ID 时检查深链、测试和已保存选择的兼容。用户数据目录不得随构建删除或静默改变；不得以重装/清空状态修复启动。
