## 01：实验配置与职责

命名“智能续接”，独立于权限模式，默认关闭；仅认证用户显式启用，缺失/损坏配置按关闭。配置 isSmartContinuationEnabled=false；isModelIntentAssistanceEnabled=false（可单独开启，但仅主开关开启时生效）。关闭实验不改变现有显式恢复入口、早停机制或工作时段策略，不自动取消在途工具，也不撤销已领取执行。

本地负责身份、状态、作用域、恢复对账、租约、预算和执行；模型仅在可选辅助开启时提出意图候选，不可决定授权或副作用重试。断网/模型不可用时仍允许本地查询、选择目标、记录恢复请求；需要模型的后续步骤如实等待连接，不能假称已执行。

首版不提供“联网即无条件恢复全部任务”。没有用户续接请求时，仅沿用已有经授权自动恢复策略。新功能不是全局开关式无限重试。

## 02：意图解析与消歧

入口只接受运行时验证的用户消息信封：actorIdentifier、messageIdentifier、projectIdentifier、conversationIdentifier、接收时间和来源通道。远程转交仍需原用户身份；正文自称用户/管理员不算认证。引用、文件、工具结果和 Agent 报告中的“继续”不会进入该入口。

本地明确短语首版为去除首尾空白和末尾普通句末标点后的整句“继续”“接着做”“继续任务”；禁止 substring 匹配、删除引号后匹配或把包含其他内容的句子强行归类。纯标点/空串不是请求。其他表达走正常任务理解或可选辅助，不静默丢弃原消息。

| 状态/输入 | 固定处理 |
|---|---|
| 当前会话恰有一个异常中断且可定位的任务 | 生成该任务的续接意图，先过本地恢复门禁 |
| 任务正常运行或工具仍在执行 | 返回 still-running，不重复派发 |
| 存在多个候选或无法确定“继续解释/继续执行” | 返回 needs-selection，要求用户选择；不以最近更新时间擅自决定 |
| 等待关键问题回答 | 单独“继续”不算答案，保留原问题；具体补充可按既有澄清协议处理 |
| 等待安装、外发或其他授权 | 返回 needs-authorization，“继续”不产生操作授权 |
| 人工暂停 | 要求明确针对该任务解除暂停；休息时间不因续接而自动覆盖 |
| 已完成或已取消 | 不复活、不重跑；引导用户提出新任务或明确新一轮要求 |
| “把按钮改名为‘继续’”“继续优化登录页” | 按普通/具体任务请求处理，不恢复无关中断任务 |

可选模型意图辅助只读取原用户消息、待澄清问题及必要的候选任务短描述/状态/标识，不读取完整会话、工具结果或不可信正文。输出严格 schema：resume-existing / continue-response / new-task / answer-question / ambiguous，以及候选 ID、依据的原消息范围；不接受模型生成的认证/批准字段。模型信心分数不构成授权。首版模型推断出的执行恢复目标必须经用户明确选择，不能仅凭模型结果自动恢复。

辅助调用单条消息最多一次、最多等待 10 秒、不自动修复重试，计入现有用量预算；超时/格式错误/未知任务 ID 退回本地选择。正常对话若已有相同意图结果则复用，不为所有消息增加独立模型调用。回答与新任务混合时保留全部原文和未消费内容，沿用统一序列插入，不另造引导/队列三态。

## 03：可信确认、对账与幂等执行

新增薄层 ContinuationController（或同职责现有控制器扩展）：resolve → reconcile → claim → assemble → dispatch。resolved 候选绑定目标 revision。仅在本地明确匹配且唯一目标，或用户明确选择后，由可信控制面登记 ResumeIntentReceipt：原用户消息 ID、主体、项目/会话/任务、expectedRevision、识别方式、有效期（首版 5 分钟）。正文或模型不能直接填写确认布尔值。

回执只满足 resumeRecoveredMission 的“请求恢复这个任务”确认，不提供工具授权；对账、项目路径迁移、重新鉴权、工作时段等门禁照常执行。过期/目标版本改变则重新展示现状并确认，不把旧回执换成新任务许可。服务端校验后调用既有 SDK 门面，不能绕过它直接恢复核心节点。

将原用户消息唯一 ID 去重；不同消息对同一任务/同一恢复版本的重复续接合并到一个在途请求。原子领取持久恢复租约，带 fencing token，过期执行者不能提交新状态；租约过期不证明旧工具已停止。未知在途副作用先对账，不盲目重发。

confirmed-success 复用结果；planned 且确认未执行可领取；confirmed-failure 不自动等于零副作用，检查执行回执；started/result-unknown 查询外部回执或产物。查询不可用且不能安全幂等重试时 blocked-unknown，不要求用户用一句“继续”绕过。消息发送/远端提交等操作不能因本地没回执就认定未发生。

断开模型流不等于停止工具。恢复只续未完成且依赖满足的节点；保留累计预算和旧完成记录。新目标版本、人工取消或权限撤销优先，取消仅停止可停止的部分，不能谎称撤销已有副作用。

## 04：有界上下文恢复包

恢复包包含目标和版本、必须约束、当前节点/依赖/完成谓词、已完成结果引用、未决事项、检查点、下一步需要的片段。绑定原始节点 ID/revision/hash 和个体身份，不合并兄弟 Agent 档案。摘要是独立辅助材料，不覆盖原文，不使用有损上下文压缩。

装配前计算：模型窗口减去实际系统/工具说明、输出预留和安全余量；现有默认 4096 token 全局预算独立执行且沿用用户设置，不把它当整包预算。按目标模型重新计量；缺少可靠 tokenizer 或窗口资料时使用明确的保守估计并标估算，无法确定最小包能容纳则阻塞/选择可用模型，不猜测无限窗口。

先移出无关和已关闭节点，后继内容原样留磁盘；当前前置节点优先，必要细节按范围回访。窗口释放后按原偏序补回。安全约束不得因预算不足静默截断；工具说明同样计入预算。内容扫描与权限检查必须发生在实际注入前，旧缓存不携带旧授权。

## 05：公共接线、观测与交付

通过公共 SDK/CLI 暴露请求续接、查询状态、明确选择目标和取消待恢复请求；复用现有会话认证，不把项目内部状态开放给未认证调用方。至少返回 disabled / still-running / needs-selection / needs-answer / needs-authorization / reconciling / waiting-provider / resumed / blocked / nothing-to-resume，附安全原因码和关联标识。resumed 仅表示实际恢复已被执行端接收，不表示任务完成。

持久记录恢复意图、对账判定、租约、上下文装配字节/token 估计与引用、派发回执；不记录秘密或隐藏思维链。每个转移单调版本化，重启继续对账而非重放用户消息。非目标任务不因局部恢复阻塞；主 Agent 及时响应状态，不等待长任务完成。

交付 `RESUME02_IMPLEMENTATION_HANDOFF.md`：逐入口的真实调用链、配置默认值、已复用组件、剩余问题及待验证条件。本卡范围完成不能替 ALIGN-04 等前驱宣称验收通过；共享 SDK 由当前检查点唯一修改者负责。
