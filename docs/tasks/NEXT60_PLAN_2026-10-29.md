## 3. 每轮固定动作

1. 读相关源码（不猜）；
2. 只改本检查点文件；
3. `npm run typecheck` / `npx eslint <改动文件>` / `npm run build`；
4. 更新任务卡与 `PLAN_STATUS`（编号连续）；
5. **显式路径** `git add` → `git status --porcelain` 核对 → 提交 → `git push`（≤5 次，失败记录）；
6. 隐私自检（无真实用户名/凭据/内网 IP/私有仓名）。

## 4. 明确不做 / 需用户决定

- **不伪造运行证据**；测试与实机验证需用户明确授权。
- **REMOTE-01 真实投递**：平台阻塞，需用户提供测试租户/验签向量/回执接口。
- **死常量 A/B**：需用户拍板（推荐 A）。
- **不自动修复两套记账**：只生成提案。
- **不改写远端历史、不强推**。
- 不提交工作区中**非本轮**的未跟踪/已修改文件（例如 R1 时存在的
  `docs/tasks/RESUME02_EXPERIMENTAL_SMART_CONTINUATION.md` 改动）。
