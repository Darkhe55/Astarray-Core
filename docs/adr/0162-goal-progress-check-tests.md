# ADR-0162 每三组进展检查的单元验证（R99，2026-11-01）

- 状态：已采纳（单测；真实多组 mission 仍未演练）
- 来源：用户"继续推进任务卡"；卡验收条件"无进展能暂停"
- 相关：ADR-0076（门禁）、ADR-0126/0130（组性质）、ADR-0139（完成耦合）

## 1. 覆盖内容

新增 `tests/core/goal-progress-stagnation.test.ts`（4/4）：

1. **普通组连续三次检查 V 未降 ⇒ 暂停**：首次检查建立基准（不计数），第 6/9/12 组三次未降后
   `isPaused=true`，`pauseReason` 含"连续"；
2. **返工组不计入停滞**：到达检查点时 `didRunProgressCheck=true` 但计数保持 0、不暂停；
3. **V 实际下降 ⇒ 计数清零**：第 6 组 V 从 3 降到 2，计数归零；
4. **模型伪造被拒**：`recordedBy` 非 `local-verifier` ⇒ 抛 `task-sequence-permission-denied`。

## 2. 意义

卡里 "无进展能暂停" 与 "调查/返工暂时不罚" 两条规则此前只有实现、**没有针对性测试**；
现在有了可重复的单元证据（门禁逻辑层）。
