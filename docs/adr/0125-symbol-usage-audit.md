## 1. 背景

R43 的证据索引是**手写的符号—文件—行号**清单，行号会漂移，符号也可能被改名/删除。
没有任何自动校对，索引本身可能悄悄过期。

## 2. 交付

1. `scripts/manual/symbol-usage-audit.mjs`（**只读**）：
   - 内置 29 个来自证据索引的符号与定义文件；
   - 统计每个符号在 `packages/`（`.ts`）与 `scripts/`（`.mjs`）中的出现次数；
   - 区分**定义文件内**与**外部引用文件数**；
   - 输出"未找到 / 仅定义处 / 有外部引用"三态表格与汇总。
2. 生成报告 `docs/reports/SYMBOL_USAGE_AUDIT_2026-10-29.md`（本次实际运行）。

## 3. 本次结果（真实输出）

- **29 个符号全部找到**（未找到 0）；
- **仅定义处 0**：每个符号至少被一个其它文件引用；
- 例：`recordGroupCompletion` / `recordToolCallConsumed` 因 R38 已有生产调用方；
  `saveActivated` 由 `application-runtime` 的 `createGoalContract` 调用。

## 4. 这份审计能说明什么 / 不能说明什么

**能**：证据索引里的符号**没有过期**（仍存在且被引用）；能发现改名/删除导致的悬空条目。

**不能**：
- 不能证明"引用即正确"（可能引用的是同名不同物，或引用点本身未被调用）；
- 不能替代行号核对（脚本不读行号）；
- 不是运行验证：**不执行任何产品代码**，只数文本。
