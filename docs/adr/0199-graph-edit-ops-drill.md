# ADR-0199 图变更四操作的确定性演练（R144，2026-11-03）

- 状态：**已实现并稳定通过**
- 来源：用户"继续推进任务卡"（GOAL-02 图变更联动剩余覆盖）
- 相关：ADR-0194（注入演练）、ADR-0195（V 上升分支）

## 1. 内容

在同一个"权限阻塞 ⇒ 安全点"夹具内，依次执行四种图变更并断言：

```
注入 T-99（依赖 T-001）→ 修订（description/toolNames）→ 重连（仍依赖 T-001）→ 删除 T-99
```

断言：

- 每一步 `outcome` 正确（injected/revised/rewired/removed）；
- 任务链最终**不含 T-99**；
- 审计按序落盘：`inject → revise → rewire → remove`；
- 目标仍 `requiresReplanning=false`、`pauseReason=null`（V 未上升）。

## 2. 过程中发现的真实行为

第一次实现直接 `注入（无依赖）→ 修订 → 重连` 时，重连被拒 `not-safe-point`：

- 修订成功后会 `wake()`，调度器**立刻启动** T-99（它无依赖）；
- 于是有在途任务 ⇒ 重连（要求安全点）被拒。

这不是缺陷（重连刻意要求安全点），但演练必须把任务保持 pending：
改为注入时依赖**被权限阻塞的 T-001**，修订/重连后仍 pending，删除才可稳定执行。

## 4. 覆盖与未覆盖

**覆盖**：注入/修订/重连/删除四操作的真实联动，及审计顺序、目标不暂停。

**未覆盖**：
- 删除**已映射**任务的映射清理联动（只有存储单测）；
- "有在途任务时重连被拒"没有专测（本次是演练中观察到的行为）；
- 真实 mission（非权限阻塞夹具）的四操作演练；
- investigation 组的真实任务演练（需要全只读 mission 跑完组）。
