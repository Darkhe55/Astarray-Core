# ADR-0076 目标模式本地门禁与有界绕行（GOAL-02-02）

- 状态：部分采纳（门禁状态机；未接进派发、未持久化）
- 日期：2026-10-28
- 来源：[GOAL-02](../tasks/GOAL02_BOUNDED_GOAL_STABILITY.md) 检查点 02
- 相关：ADR-0075（目标契约与 V）

## 1. 背景

GOAL-02-01 只交付了契约与纯计算，没有任何执行侧约束：目标模式不会拦截、暂停或校验派发。
本检查点补上"本地门禁"，但仍**不替代**工具权限、备份门禁与预算系统 —— 它只回答
"这次派发是否仍与固定目标版本一致、是否该暂停"。

## 2. 契约（冻结）

1. **派发前检查**（`assertDispatchAllowed`）逐项返回具体原因码：
   `goal-paused` / `requires-replanning` / `revision-mismatch` / `scope-violation`
   （项目或工具不在白名单）/ `deadline-passed` / `budget-exhausted`。
   允许时给出剩余工具预算与"距下次进展检查还有几组"。
2. **按"已结束任务组"计数**：`recordGroupCompletion` 每 **3 组**做一次进展检查
   （完成与中断都计组；不看启动次数）。
3. **有界绕行**：`groupKind` 为 `investigation`/`rework` 的组**不计入停滞**（允许调查、
   测试、必要返工暂时不降 V），但仍计入组数。
4. **停滞暂停**：普通组连续 **3 次检查** V 未严格下降 ⇒ 暂停该目标自动派发，
   并给出证据缺口；**不自动无限重试、不自动申请额外资源**（没有这些入口）。
5. **证据失效**：`recordEvidenceInvalidation` ⇒ 记录事实（新 V、失效要求、原因）、
   置 `requiresReplanning`、暂停；**没有任何修改权重的入口**（结构上禁止掩盖倒退）。
6. **模型不得伪造**：`recordGroupCompletion` 要求 `recordedBy: "local-verifier"`
   （类型 + 运行时双重校验）；模型只能提出动作与解释。
7. **门禁不越权**：本类不调用工具、不写文件、不放宽任何权限；每次副作用仍走原门禁。

## 3. 生产调用链（当前）

**没有生产调用链**：`GoalDispatchGate` 是进程内状态机，尚未接入 `MissionOrchestrator` /
派发循环 / 任务序列控制器。这也是"门禁存在但没人问它"的如实状态。

## 4. 未完成（如实）

- **未接进派发**：没有调用方；目标模式目前不改变任何真实派发行为。
- **未持久化**：计数、暂停原因、证据缺口都在内存里，重启归零（属 GOAL-02-03）。
- **没有 UI/CLI**：用户看不到暂停原因与证据缺口，也没有"继续/重定向/补预算"入口。
- **预算边界只是目标级**：`maximumToolCalls` 是目标契约里的上限，没有与既有调度预算
  做"取更严"的合成（说明：两者都在时取各自拦截，效果是更严，但没有统一计算）。
- **`deadlineIso` 与暂停条件的关系未建模**：`pauseConditions` 字段存在但没有评估逻辑。
- **未验证**：没有跑过"三组不降 ⇒ 暂停""调查组不罚""模型伪造被拒""证据失效 ⇒ 暂停且权重不变"
  任何一条。
